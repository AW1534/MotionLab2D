MotionLab 2D Overview

A-Level Computer Science NEA

MotionLab 2D

A lightweight 2D physics simulator and visualiser designed to help students and teachers understand core mechanics concepts in real time.

Developer

Andrew Wiltshire

Built with

C++ · Qt6 framework

Target audience

A-Level & GCSE Physics students and teachers

Curriculum focus

A-Level Physics & Mechanics (AQA)

The problem

  • →Static diagrams and equations don't show how physical systems evolve over time, making concepts like forces, vectors and momentum hard to grasp.
  • →Existing simulation tools are either too complex, commercial, or not designed with A-Level content in mind.
  • →There is no lightweight, accessible tool that lets students build scenarios and experiment with parameters like mass, velocity and applied forces in real time.

MotionLab 2D addresses this by providing a real-time 2D simulation with visual vector overlays, an intuitive scene editor, and a clean presentation mode — all in a single portable binary that runs on school computers without installation. Physics is handled by a custom engine implementing Velocity-Verlet integration, simplified collision detection and A-Level force models.

Key features

  • ◆Create, move and delete objects with adjustable mass, velocity and applied forces
  • ◆Live vector overlays showing velocity, acceleration and force arrows
  • ◆Edit mode and Play mode — switch between building and observing
  • ◆Undo / redo system for safe experimentation
  • ◆Save and load scenes for lesson preparation
  • ◆Gravity, applied forces and collision simulation
